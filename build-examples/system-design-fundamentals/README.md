# System Design Fundamentals

A single-page educational website that teaches the core concepts of system design in a clear, scannable, and visually engaging way.

## How to View
To view the page, simply open `index.html` in any modern web browser.

## Features
- 10+ core system design sections with examples and diagrams.
- Clean, responsive design with a sticky sidebar.
- Dark mode support with persistence.
- Reading progress bar and scroll-spy navigation.
- Pure CSS diagrams (no external images).
- Fully offline-capable (no external dependencies).
